# 40-Hz Auditory Stimulation

A web app that generates 40-Hz auditory stimulation for gamma entrainment, replicating the exact methodology from the January 2026 PNAS primate study.

## Scientific Background

### The Theory

Forty-hertz (40-Hz) oscillations are high-frequency gamma brainwaves generated by synchronized neural network activity. These oscillations appear to be attenuated in the brains of Alzheimer's disease (AD) patients. Research pioneered by Tsai's group at MIT showed that 40-Hz sensory stimulation can induce gamma oscillations in the brain, which:

1. **Enhance glymphatic clearance** - 40-Hz stimulation increases astrocyte aquaporin-4 polarization, enhances arterial pulsatility, and dilates meningeal lymphatic vessels
2. **Accelerate CSF flow** - This promotes cerebrospinal fluid influx into brain tissue and efflux of interstitial fluid
3. **Clear amyloid-beta** - The enhanced fluid dynamics help remove Aβ proteins and other metabolic waste from the brain

### The PNAS 2026 Primate Study

A [January 2026 study](https://www.pnas.org/doi/10.1073/pnas.2529565123) from the Kunming Institute of Zoology provided the first non-human primate evidence for 40-Hz auditory stimulation therapy. Published in the *Proceedings of the National Academy of Sciences*, key findings include:

- **Subjects**: Nine aged rhesus macaques (26-31 years old) with naturally-developed amyloid plaques
- **Protocol**: 1 hour of 40-Hz auditory stimulation daily for 7 consecutive days
- **Results**:
  - Aβ42 protein levels in CSF increased by 205.61 ± 27.84%
  - Aβ40 protein levels increased by 201.00 ± 20.98%
- **Duration of effect**: Unlike rodent studies where effects disappeared after 7 days, the elevated Aβ levels in primates persisted for more than 5 weeks
- **Significance**: First primate evidence that 40-Hz auditory stimulation can sustainably modulate Aβ metabolism in the brain

## Audio Implementation

This app replicates the exact auditory stimulus parameters from the PNAS study:

| Parameter | Study Protocol | This App |
|-----------|---------------|----------|
| Tone frequency | 1 kHz pure tone | 1000 Hz sine wave |
| Burst duration | 1 ms | 1 ms (0.001 seconds) |
| Repetition rate | 40 Hz (every 25 ms) | 40 Hz (setInterval at 25 ms) |
| Session duration | 1 hour daily | 60-minute timer |
| Treatment period | 7 consecutive days | User-managed |
| Intensity | 60 dB | User-adjustable volume |

### How It Works

The stimulation consists of **click trains** - brief 1-millisecond bursts of a 1 kHz pure tone, repeated 40 times per second. This is different from continuous amplitude modulation; each "click" is a discrete sound event that creates the 40-Hz rhythm perceived by the auditory system and transmitted to the temporal cortex and hippocampus.

```
Sound pattern (not to scale):

|█|                       |█|                       |█|
0ms                      25ms                     50ms
 └── 1ms burst            └── 1ms burst            └── 1ms burst
     of 1kHz                  of 1kHz                  of 1kHz
```

## Features

- Exact replication of PNAS 2026 study methodology
- 60-minute countdown timer matching the study protocol
- Adjustable volume control
- Visual pulse indicator and waveform display
- Pulse counter showing total stimulation events
- **Background playback support** - Uses Screen Wake Lock API to continue playing when screen is off
- Mobile-friendly design

## How to Run

### Option 1: Open Directly

Simply open `index.html` in your web browser by double-clicking the file.

### Option 2: Local Server (Recommended)

**macOS/Linux:**
```bash
cd auditory-therapy
python3 -m http.server 8000
```
Then visit http://localhost:8000

**Windows (with Python):**
```bash
cd auditory-therapy
python -m http.server 8000
```
Then visit http://localhost:8000

### Other Options

- **Node.js**: `npx serve`
- **VS Code**: Use the [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)

## Mobile Usage Notes

- **Android**: Works well with Screen Wake Lock - audio continues with screen on dim
- **iOS Safari**: Background audio has limitations; adding to home screen may help
- **Headphones recommended**: Most devices are more permissive with audio output to headphones
